# Project Roadmap

The project has two connected tracks: complete the Pokémon Platinum
decompilation, then provide a reproducible development and runtime workflow on
Omarchy Linux.

## Current milestones

| Milestone | Exit condition | Status |
| --- | --- | --- |
| M1 — Agent workflow | Guidance, roles, templates, and validation gates are documented | Complete |
| M2 — Decompilation inventory | Remaining code, data, tooling, and tests are tracked | Not started |
| M3 — Decompilation completion | Matching build and documented coverage meet project criteria | Not started |
| M4 — Omarchy target decision | Runtime strategy and supported scope are recorded | Not started |
| M5 — Omarchy workflow | Clean setup, build, launch, input, persistence, and regression checks pass | Not started |
